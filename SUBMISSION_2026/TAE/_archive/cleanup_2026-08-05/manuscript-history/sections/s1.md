## 1 Introduction <!-- page budget: 1.0 pg -->

Runtime governance layers for language-model agents are proliferating, and most share one shape. A
rule fires on a proposed action, the agent is told which rule it broke, and it is asked to try again.
AgentSpec, NeMo Guardrails, PolicyGuard and SAVeR all work this way, and all report success as a
conformance number, violations before enforcement against violations after. The shape is older than
the systems. Normative multi-agent systems have separated regimentation, which makes a violation
impossible, from enforcement, which detects one and responds, for twenty-five years, and AMELI, OperA
and MOISE+ each built an institution around it.

What a conformance number measures depends on what the norm reads. A rule can condition on state the
environment records, a budget, a file, an allocation cap. It can equally condition on state the agent
itself reports in the same generation being judged, how severe it says a shortage is or how
threatened it says it feels. The second case has not been examined, and it is the one this paper is
about.

Enforcing over model-authored state is not new and we do not claim it. AgentSpec's rule language
places no constraint on what a predicate may read, so a rule that fires on a self-reported appraisal
is well formed in it today, and SAVeR already verifies over an agent's internal belief states before
an action is committed. What follows is an evaluation result, not a mechanism.

The property that does the work is not endogeneity. A predicate over program state after an agent has
edited files is treatment-affected as well; Gao et al. name post-treatment risk-set bias in agentic
code repair and offer a remedy, branching from frozen common states, which is available because their
conditioning variable is external to the generation. For a world predicate there is an observation
channel independent of what the agent writes, since the filesystem can be read, the budget checked,
the state frozen and re-entered. For a self-reported predicate the only channel is the generation
being governed. Enforcement rewrites the distribution of its own antecedent and cannot be made not
to, since freezing the appraisal destroys the thing being measured.

We measure what this does to a reported gain, on paired runs with validators and without, in two
agent testbeds. The conditioning variable moves further than the rate it supports, the movement is
composition of world states rather than an agent working around the rule, and on one configuration
the whole apparent gain is composition. The obvious repair, conditioning the norm on world state
instead, fails on the same corpus.
