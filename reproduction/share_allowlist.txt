# Run-folder files that may be shared with a reader of the paper.
# One pattern per line, matched case-sensitively one path part at a time against the path
# relative to the run folder: a pattern without "/" matches only files at the top of the
# run folder ("*" never crosses a "/"). Links inside a run folder are never followed.
# Used by reproduction/check_share.py. Copy these files with
#   python reproduction/check_share.py --stage <dest> <run-folder>
# which blanks absolute paths in the copy, then checks the copy.
#

# scripts read. Run records, configuration, and per-decision audit tables only.
