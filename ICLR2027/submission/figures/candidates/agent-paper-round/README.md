These candidates were generated after comparing the rendered figures in
ReAct, Reflexion, AutoGen, SWE-agent, and AgentSpec. They remain comparison
artifacts and are never referenced by `paper/manuscript.tex`.

- `figure1_agentpaper_candidate_dual_panel_v1.png`: clear runtime/measurement
  split, but its cross-panel shared-condition bridge lacked a fully explicit
  endpoint.
- `figure1_agentpaper_candidate_interface_v1.png`: compact interface layout,
  but the amber condition route could be misread as entering Decision log.
- `figure1_agentpaper_candidate_nested_v3.png`: selected nested-interface
  composition. It makes Validator's insertion point explicit, gives Counted
  set separate condition and records inputs, uses black borders with flat
  colored fills, removes an ambiguous retry connector, and anchors every
  action/condition/observation arrow to a semantic node.
