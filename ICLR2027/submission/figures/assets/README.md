# Figure 1 generated assets

`figure1_architecture_agentpaper_v3.png` is the reviewed generated
shared-condition bridge used by the active ICLR manuscript. It contains the
LLM cue, functional icons, black borders, colored fills, arrows, labels, and
background as one generated raster image. Its compact grid separates runtime
from measurement; the Agent boundary owns the response, the accepted-decision
route terminates on Decision log, and the shared condition routes directly to
Filter.

Other files in this directory are generation intermediates or historical style
references. They are not active manuscript figures. Run
`source/figure1_overlay.py` to stage the reviewed asset into `figures/active/`.
