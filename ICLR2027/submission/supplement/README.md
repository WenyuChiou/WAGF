# Supplementary release package

This directory contains the small, non-identifying evidence package that
travels with the ICLR draft.

- `reproducibility_inventory.csv` records the frozen run inventory.
- `table1_cells.csv` records the paired irrigation-cell quantities used in the
  manuscript. Its Flood gemma3:4b row is retained as a clearly labelled B6
  included-run sensitivity record; the release result is in
  `cross_testbed_summary.csv` and `flood_control_contrasts.csv`.
- `fig1_rule_layers.csv`, `fig2_mechanism.csv`, and `fig3_consequence.csv` are
  the machine-readable source values behind Figures 2--4. The active
  `fig2_mechanism` CSV contains only the three primary irrigation panels.
  `fig3_denominator_gap.csv` is the copied, executed-action data behind the
  active Figure 4 slope plot; `fig3_consequence.csv` remains the source table
  containing both action readings for the declared sensitivity analysis.
- `cross_testbed_summary.csv` and `table2_cross_testbed.tex` are generated by
  the active cross-testbed builder. They keep Flood as a secondary numerical
  boundary check rather than a same-status mechanism panel.
  `enforcement_pressure_source.json` pins the reported governance-pressure
  ranges and their handoff source.
- `WORLD_REWEIGHTING_DIAGNOSTICS.md` keeps the pooled and per-seed estimates
  separate for the full frozen stratification ladder.
- `FIGURE_REGENERATION.md` records the regeneration commands and their source
  boundary.
- `FIRST_ATTEMPT_LIMITATIONS.md` records the fields that are not available in
  the frozen corpus.

The package does not claim full bitwise reproduction of every historic run.
The source-run provenance limitations remain disclosed in the paper. The
supplement contains no private credentials, local paths, or identifying model
metadata.
